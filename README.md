# LIMA-atividades
Resolução de Exercícios – LIMA
Este diretório contém as resoluções dos exercícios desenvolvidos na disciplina de LIMA (Linguagem de Marcação).
O objetivo é reunir as atividades realizadas ao longo da disciplina, registrando a aplicação dos conceitos estudados e servindo como material de consulta para revisões e aperfeiçoamento dos conhecimentos.
Conteúdo
Os exercícios abordam temas como:
XML
HTML
Estruturação de documentos
Sintaxe de linguagens de marcação
Validação de documentos
Correção de erros estruturais
Objetivos
Aplicar os conceitos de Linguagem de Marcação.
Desenvolver documentos seguindo a sintaxe correta.
Identificar e corrigir erros em arquivos de marcação.
Organizar os arquivos de forma clara e padronizada.
