# Currículo em Markdown

## Sobre o Projeto

Este projeto consiste na criação de um currículo utilizando a linguagem de marcação Markdown.

A atividade tem como objetivo aplicar os conhecimentos sobre formatação de textos, organização de informações e estruturação de documentos utilizando uma linguagem simples e eficiente para criação de conteúdos digitais.

## Objetivo da Atividade

Desenvolver um currículo profissional utilizando Markdown, aplicando recursos como:

- Títulos e subtítulos;
- Listas organizadas;
- Formatação de textos;
- Separação de seções;
- Estruturação de informações profissionais.

## Estrutura do Currículo

O currículo foi organizado nas seguintes seções:

### Informações Pessoais

Apresenta dados básicos de identificação, como nome, contato e localização.

### Objetivo Profissional

Descreve as áreas de interesse e objetivos relacionados à carreira profissional.

### Formação Acadêmica

Apresenta informações sobre cursos, instituições de ensino e períodos de estudo.

### Experiências Profissionais

Lista experiências anteriores, atividades realizadas e conhecimentos desenvolvidos.

### Habilidades

Apresenta competências técnicas e pessoais, como conhecimentos em ferramentas, tecnologias e trabalho em equipe.

### Cursos e Certificações

Exibe cursos complementares e qualificações realizadas.

## Tecnologias Utilizadas

- Markdown

## Conceitos Aplicados

Durante o desenvolvimento do currículo foram utilizados:

- Estruturação de documentos em Markdown;
- Uso de títulos e subtítulos;
- Criação de listas;
- Destaque de informações importantes;
- Organização e apresentação de conteúdo profissional.

## Vantagens do Markdown

O uso do Markdown permite criar documentos organizados de forma simples, com boa legibilidade e fácil conversão para diferentes formatos, como páginas web e documentos digitais.

## Conclusão

A criação do currículo em Markdown possibilitou desenvolver habilidades de organização de informações e utilização de uma linguagem de marcação leve, muito utilizada em plataformas de documentação e projetos de tecnologia.
