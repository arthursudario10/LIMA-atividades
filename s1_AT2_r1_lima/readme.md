# Exercícios de XML

## Sobre o Projeto

Este projeto reúne seis exercícios práticos desenvolvidos para aplicar os conceitos fundamentais da linguagem XML (Extensible Markup Language).

As atividades têm como objetivo compreender a estrutura de documentos XML, criação de elementos, organização de informações e utilização de boas práticas na construção de dados estruturados.

## Objetivo dos Exercícios

Praticar os principais conceitos do XML, incluindo:

- Criação de documentos XML;
- Uso correto de elementos e atributos;
- Organização hierárquica das informações;
- Estruturação de dados;
- Validação e padronização de documentos XML.

## Exercícios Desenvolvidos

### Exercício 1 - Estrutura Básica do XML

Criação de um documento XML simples utilizando a declaração inicial, elementos principais e organização das informações.

**Conceitos aplicados:**
- Declaração XML;
- Elementos;
- Estrutura hierárquica.

---

### Exercício 2 - Cadastro de Informações

Desenvolvimento de um XML para armazenar informações de cadastro, utilizando diferentes elementos para representar os dados.

**Conceitos aplicados:**
- Criação de tags personalizadas;
- Organização de dados;
- Identificação de informações.

---

### Exercício 3 - Uso de Atributos

Criação de um documento XML utilizando atributos para adicionar informações complementares aos elementos.

**Conceitos aplicados:**
- Atributos XML;
- Identificação de elementos;
- Estruturação de dados.

---

### Exercício 4 - Lista de Dados

Construção de uma lista de informações utilizando elementos repetidos dentro do XML.

**Conceitos aplicados:**
- Elementos múltiplos;
- Organização de coleções;
- Hierarquia de informações.

---

### Exercício 5 - Estrutura de Dados Complexa

Criação de um XML com diferentes níveis de organização, representando informações relacionadas entre si.

**Conceitos aplicados:**
- Elementos pai e filho;
- Aninhamento de tags;
- Estrutura hierárquica.

---

### Exercício 6 - Validação e Boas Práticas

Aplicação de regras de organização e padronização para garantir que o documento XML esteja bem estruturado.

**Conceitos aplicados:**
- Sintaxe XML;
- Fechamento correto de tags;
- Organização e legibilidade.

---

## Tecnologias Utilizadas

- XML (Extensible Markup Language)

## Conceitos Aprendidos

Durante a realização dos exercícios foram trabalhados:

- Estrutura de documentos XML;
- Criação de elementos;
- Utilização de atributos;
- Organização de informações;
- Hierarquia de dados;
- Boas práticas de escrita XML.

## Conclusão

Os exercícios permitiram compreender como o XML é utilizado para representar e organizar informações de forma estruturada, facilitando o armazenamento, compartilhamento e interpretação de dados entre diferentes sistemas.
