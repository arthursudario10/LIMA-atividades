
# Página Pessoal em HTML

## Sobre o Projeto

Este projeto foi desenvolvido como uma atividade prática da disciplina de desenvolvimento web, com o objetivo de aplicar os conhecimentos sobre a linguagem de marcação HTML e a utilização de elementos semânticos.

A página representa um site pessoal contendo informações sobre mim, meus hobbies e meus objetivos para o futuro profissional.

## Objetivo da Atividade

Praticar a criação de uma estrutura HTML organizada, utilizando boas práticas de desenvolvimento web, com foco em:

- Organização do conteúdo;
- Uso correto de tags semânticas;
- Estruturação de uma página acessível;
- Compreensão da hierarquia das informações.

## Estrutura da Página

A página foi organizada nas seguintes partes:

### Cabeçalho (`<header>`)

Responsável por apresentar o nome da página e identificar o conteúdo principal do site.

### Seção Sobre Mim (`<section>`)

Apresenta informações pessoais, interesses e características do autor da página.

### Seção Hobbies (`<section>`)

Exibe uma lista com atividades e interesses pessoais do cotidiano.

### Seção Futuro Profissional (`<section>`)

Apresenta objetivos, planos e expectativas para a carreira profissional.

### Rodapé (`<footer>`)

Contém informações de autoria e copyright da página.

## Tecnologias Utilizadas

- HTML5

## Conceitos Aplicados

Durante o desenvolvimento da página foram utilizados:

- Estrutura básica de um documento HTML;
- Elementos semânticos;
- Cabeçalhos e parágrafos;
- Listas HTML;
- Organização de conteúdo;
- Boas práticas de acessibilidade.

## Acessibilidade

O uso de elementos semânticos como `<header>`, `<section>` e `<footer>` permite uma melhor interpretação da estrutura da página por navegadores e leitores de tela.

A organização correta do HTML facilita a navegação dos usuários e contribui para uma experiência mais acessível.

## Comentário Reflexivo

Os elementos semânticos utilizados foram escolhidos para criar uma estrutura lógica e organizada. O uso de tags como `<header>`, `<section>` e `<footer>` permite que cada parte da página tenha uma função específica, facilitando a compreensão do conteúdo por usuários e tecnologias assistivas, como leitores de tela.
